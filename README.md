# 🏢 Society Management System

A full-stack web application designed to simplify residential society management by providing digital solutions for visitor tracking, resident management, complaints, announcements, and community communication.

## 📌 Project Overview

The Society Management System helps residents, security guards, and administrators manage day-to-day society operations efficiently. The platform reduces paperwork, improves communication, and enhances security through a centralized dashboard.

---

## ✨ Features

### 👨‍💼 Admin Features
- Manage residents and flats
- View society statistics
- Approve or reject resident requests
- Create announcements and notices
- Monitor visitor records
- Manage complaints and maintenance requests

### 🏠 Resident Features
- Register and login securely
- View society announcements
- Raise complaints and track status
- Manage profile information
- View visitor history
- Receive notifications and updates

### 🚪 Visitor Management
- Visitor registration
- Entry and exit tracking
- Visitor approval workflow
- Visitor history records
- Security monitoring dashboard

### 🔐 Authentication & Security
- JWT-based authentication
- Protected routes
- Role-based access control
- Secure password storage

### 📱 Responsive Design
- Mobile-friendly interface
- Responsive dashboards
- Cross-browser compatibility
